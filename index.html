Section A Question 1: Exponential Functions and Modelling
Problem 1.1

A bacteria culture grows with a constant relative growth rate. The bacteria count was 400 after 2 hours and 25,600 after 6 hours.

  • (a) What was the initial size of the culture?
  • (b) Find an expression for the number of bacteria after \(t\) hours.
  • (c) When will the population reach 50,000?
Use $P(t) = P_0 e^{kt}$. From $t=2$ to $t=6$ is $\Delta t = 4$ hours. The factor increase is $\frac{25600}{400} = 64$. Thus $e^{4k} = 64 = 8^2 \implies e^{2k} = 8$. Then $P_0 = \frac{400}{e^{2k}} = \frac{400}{8} = 50$.
Problem 1.2

Evaluate the indefinite integral using exponential laws and substitution:

\[\int e^{e^u + u} \, du\]
Rewrite $e^{e^u + u}$ as $e^{e^u} \cdot e^u$. Substitute $w = e^u$, which gives $dw = e^u du$. The integral becomes $\int e^w dw = e^w + C = e^{e^u} + C$.
Problem 1.3

Solve the differential equation involving separable exponential variables:

\[\frac{dy}{dx} = \frac{x^3}{e^y}\]
Note: This aligns with Question 8 on your 2026 exam breakdown
Separate variables: $e^y dy = x^3 dx$. Integrate both sides: $e^y = \frac{x^4}{4} + C \implies y = \ln\left(\frac{x^4}{4} + C\right)$.
Section A Question 2: Hyperbolic Functions and Differentiation
Problem 2.1

Evaluate the exact value without a calculator:

\[\sinh(3 \ln 2)\]
Use definition $\sinh(x) = \frac{e^x - e^{-x}}{2}$. Here $e^{3\ln 2} = e^{\ln(2^3)} = 8$, and $e^{-3\ln 2} = \frac{1}{8}$. So $\sinh(3\ln 2) = \frac{8 - 1/8}{2} = \frac{63}{16}$.
Problem 2.2

Let \(f(x) = \tanh(\ln x)\) for \(x > 0\). Calculate the derivative \(f'(x)\) and simplify your answer.

Chain Rule: $f'(x) = \text{sech}^2(\ln x) \cdot \frac{1}{x}$. You can also write $\tanh(\ln x) = \frac{x - x^{-1}}{x + x^{-1}} = \frac{x^2 - 1}{x^2 + 1}$ and differentiate directly to get $\frac{4x}{(x^2 + 1)^2}$.
Problem 2.3

Given that \(\tanh x = \frac{12}{13}\), determine the exact values of \(\sinh x\) and \(\cosh x\).

Identity: $1 - \tanh^2 x = \text{sech}^2 x$. So $\text{sech}^2 x = 1 - \frac{144}{169} = \frac{25}{169} \implies \cosh x = \frac{13}{5}$ (since $\cosh x > 0$). Then $\sinh x = \cosh x \cdot \tanh x = \frac{13}{5} \cdot \frac{12}{13} = \frac{12}{5}$.
Section A Question 3: Vectors and Equations of Lines
Problem 3.1

Determine the vector form of the line passing through the point \(P = (2, 1, 1)\) that runs parallel to the \(x\)-axis.

Direction parallel to the x-axis is $\mathbf{d} = [1, 0, 0]$. Vector form: $\mathbf{r}(t) = [2, 1, 1] + t[1, 0, 0]$ for $t \in \mathbb{R}$.
Problem 3.2

Determine the parametric form of the line passing through the origin perpendicular to the plane \(x - 3y + 3z = 4\).

The normal vector of the plane is $\mathbf{n} = [1, -3, 3]$, which serves as the direction vector of the perpendicular line. Passing through $(0,0,0)$, the parametric equations are $x = t$, $y = -3t$, $z = 3t$.
Problem 3.3

Find all values of \(k\) such that the vectors \(\mathbf{u} = [1, -1, 2]\) and \(\mathbf{v} = [k^2, k, -3]\) are orthogonal.

Set dot product to zero: $\mathbf{u} \cdot \mathbf{v} = (1)(k^2) + (-1)(k) + (2)(-3) = k^2 - k - 6 = 0$. Factor: $(k - 3)(k + 2) = 0 \implies k = 3$ or $k = -2$.
Section A Question 4: Limits and Indeterminate Forms
Problem 4.1

Evaluate the indeterminate power limit (\(0^0\)) using logarithmic transformations and L'Hôpital's Rule:

\[\lim_{x \to 0^+} x^{\sqrt{x}}\]
Let $y = x^{\sqrt{x}}$, so $\ln y = \sqrt{x} \ln x = \frac{\ln x}{x^{-1/2}}$. Apply L'Hôpital: $\lim_{x \to 0^+} \frac{1/x}{-\frac{1}{2}x^{-3/2}} = \lim_{x \to 0^+} (-2\sqrt{x}) = 0$. Therefore, $\lim y = e^0 = 1$.
Problem 4.2

Evaluate the indeterminate difference limit (\(\infty - \infty\)):

\[\lim_{x \to 1} \left( \frac{x}{x-1} - \frac{1}{\ln x} \right)\]
Combine denominators: $\frac{x \ln x - (x - 1)}{(x - 1)\ln x}$. Apply L'Hôpital twice to resolve the $\frac{0}{0}$ indeterminate form. The resulting limit evaluates to $\frac{1}{2}$.
Problem 4.3

Consider the limit \(\lim_{x \to \infty} \frac{2x + \sin x}{3x}\).

  • (a) Explain why L'Hôpital's Rule cannot be applied.
  • (b) Evaluate the true limit using the Squeeze Theorem.
Note: Proof/explanation format typical of Section C rather than Section A
(a) Differentiating top and bottom gives $\frac{2 + \cos x}{3}$. As $x \to \infty$, $\cos x$ oscillates continuously, meaning the derivative quotient limit does not exist. (b) Since $-1 \le \sin x \le 1$, we have $\frac{2x - 1}{3x} \le \frac{2x + \sin x}{3x} \le \frac{2x + 1}{3x}$. As $x \to \infty$, both bounds tend to $\frac{2}{3}$.
Section A Question 5: Planes, Normal Vectors and Distances
Problem 5.1

Determine the vector form, parametric form, and normal form of the plane passing through \(P = (6, -4, -3)\) with direction vectors \(\mathbf{u} = [1, 0, 2]\) and \(\mathbf{v} = [-3, 2, 1]\).

Vector u patched
Normal vector is $\mathbf{n} = \mathbf{u} \times \mathbf{v} = [-4, -7, 2]$. Normal equation: $-4(x - 6) - 7(y + 4) + 2(z + 3) = 0 \implies -4x - 7y + 2z = -2$.
Problem 5.2

Find the perpendicular distance between the point \(Q = (1, 2, 3)\) and the plane \(x - y + z = 0\), and determine the point on the plane closest to \(Q\).

Distance: $D = \frac{|1(1) - 1(2) + 1(3)|}{\sqrt{1^2 + (-1)^2 + 1^2}} = \frac{2}{\sqrt{3}}$. The closest point is found by moving from $Q$ along the unit normal: $Q - D \frac{\mathbf{n}}{\|\mathbf{n}\|} = (1, 2, 3) - \frac{2}{3}(1, -1, 1) = \left(\frac{1}{3}, \frac{8}{3}, \frac{7}{3}\right)$.
Problem 5.3

Calculate the vector projection \(\text{proj}_{\mathbf{u}}(\mathbf{v})\) where \(\mathbf{u} = [2, -1, 3]\) and \(\mathbf{v} = [1, 4, -2]\).

Vectors u and v patched
Formula: $\text{proj}_{\mathbf{u}}(\mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2}\mathbf{u}$. Compute $\mathbf{u} \cdot \mathbf{v} = 2(1) + (-1)(4) + 3(-2) = -8$. Compute $\|\mathbf{u}\|^2 = 2^2 + (-1)^2 + 3^2 = 14$. Thus $\text{proj}_{\mathbf{u}}(\mathbf{v}) = -\frac{8}{14}[2, -1, 3] = -\frac{4}{7}[2, -1, 3]$.
Section A Question 6: Integration of Algebraic and Radical Expressions
Problem 6.1

Evaluate the indefinite integral using a trigonometric substitution:

\[\int \frac{\sqrt{x^2 - 1}}{x^4} \, dx\]
Let $x = \sec\theta$, so $dx = \sec\theta\tan\theta \, d\theta$ and $\sqrt{x^2-1} = \tan\theta$. The integral becomes $\int \frac{\tan^2\theta}{\sec^3\theta} d\theta = \int \sin^2\theta \cos\theta \, d\theta$. Substitute $u = \sin\theta$, giving $\frac{1}{3}\sin^3\theta + C$. From the triangle, $\sin\theta = \frac{\sqrt{x^2-1}}{x}$, so the answer is $\frac{(\sqrt{x^2-1})^3}{3x^3} + C$.
Problem 6.2

Evaluate the indefinite integral:

\[\int \frac{1}{\sqrt{x^2 + 9}} \, dx\]
This is a standard form. Using $x = 3\tan\theta$, it simplifies to $\int \sec\theta \, d\theta = \ln|\sec\theta + \tan\theta| + C$. Converting back yields $\ln\left|\frac{\sqrt{x^2+9}}{3} + \frac{x}{3}\right| + C$, which simplifies to $\ln|x + \sqrt{x^2+9}| + C_1$.
Problem 6.3

Evaluate the definite integral using the trigonometric substitution \(5x = 3\sin\theta\):

\[\int_0^{3/5} \frac{x^2}{\sqrt{9 - 25x^2}} \, dx\]
Substitute $x = \frac{3}{5}\sin\theta$ and $dx = \frac{3}{5}\cos\theta \, d\theta$. The bounds change from $0 \to \frac{3}{5}$ to $0 \to \frac{\pi}{2}$. The denominator becomes $3\cos\theta$. The integral simplifies to $\frac{9}{125} \int_0^{\pi/2} \sin^2\theta \, d\theta = \frac{9}{125} [\frac{\theta}{2} - \frac{\sin 2\theta}{4}]_0^{\pi/2} = \frac{9\pi}{500}$.
Section A Question 7: Functions, Composition and Domains
Problem 7.1

Simplify the composite function \(f(x) = \cos(\sin^{-1} x)\) into an algebraic expression and state its exact domain \(D_f\) in interval notation.

Let $\theta = \sin^{-1} x$. By definition, this means $\sin\theta = x$ and $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$. Using a right triangle or the identity $\cos^2\theta = 1 - \sin^2\theta$, we get $\cos\theta = \sqrt{1-x^2}$ (positive root because cosine is positive on that interval). Domain: $[-1, 1]$.
Problem 7.2

State the exact domain of the hyperbolic tangent function \(g(x) = \tanh x\).

$\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$. Since $e^x + e^{-x} > 0$ for all real $x$, the denominator is never zero. Domain: $\mathbb{R}$ or $(-\infty, \infty)$.
Problem 7.3

Simplify \(h(x) = \sin(2\arccos x)\) using double-angle identities and state its exact domain \(D_h\) in interval notation.

Using $\sin(2\theta) = 2\sin\theta\cos\theta$ where $\theta = \arccos x$. We know $\cos(\arccos x) = x$ and $\sin(\arccos x) = \sqrt{1-x^2}$. Therefore, $h(x) = 2x\sqrt{1-x^2}$. Domain of $\arccos x$ dictates the domain: $[-1, 1]$.

Section A Question 9: Linear Systems and Augmented/Extended Matrices
Problem 9.1

Consider the linear system represented by the augmented matrix:

\[\left[\begin{array}{ccc|c} 1 & -2 & 3 & 1 \\ 0 & k & 2 & 4 \\ 0 & 0 & k^2 - 4 & k - 2 \end{array}\right]\]

Determine all values of the parameter \(k\) for which the system has: (a) No solution, (b) A unique solution, (c) Infinitely many solutions.

Look at the bottom row: $0x + 0y + (k^2-4)z = k-2$.
(a) No solution: $k^2-4 = 0$ AND $k-2 \neq 0 \implies (k-2)(k+2)=0$. If $k=-2$, we get $0 = -4$ (Inconsistent).
(c) Infinitely many: $k^2-4=0$ AND $k-2=0 \implies k=2$. Row becomes $0=0$.
(b) Unique: $k \neq -2$ and $k \neq 2$ (AND $k \neq 0$ for the second row pivot).
Problem 9.2

Identify the pivot variables and free variables, and write down the complete parametric solution set \([x, y, z]^T\) for the reduced row echelon system:

\[\left[\begin{array}{ccc|c} 1 & 0 & -3 & 5 \\ 0 & 1 & 2 & -1 \\ 0 & 0 & 0 & 0 \end{array}\right]\]
Pivots are $x$ and $y$. Free variable is $z$. Let $z = t$. From row 2: $y + 2t = -1 \implies y = -1 - 2t$. From row 1: $x - 3t = 5 \implies x = 5 + 3t$. Vector form: $[5, -1, 0]^T + t[3, -2, 1]^T$.

Section A Question 10: Rational Integration and Changes of Variable
Problem 10.1

Find the polynomial \(Q(x)\) in the following partial fraction decomposition:

\[\frac{3x^2 + 5x + 4}{(x+1)^3} = \frac{P(x)}{x+1} + \frac{Q(x)}{(x+1)^2} + \frac{R(x)}{(x+1)^3}\]
Multiply by $(x+1)^3$: $3x^2 + 5x + 4 = A(x+1)^2 + B(x+1) + C$. Let $x=-1 \implies C = 3(-1)^2 - 5 + 4 = 2$. Expand RHS: $Ax^2 + (2A+B)x + (A+B+C)$. Compare coefficients: $A=3$. $2(3)+B = 5 \implies B=-1$. So $Q(x) = -1$.
Problem 10.2

Evaluate the indefinite integral using partial fraction decomposition:

\[\int \frac{5x + 1}{(2x + 1)(x - 1)} \, dx\]
Decompose: $\frac{A}{2x+1} + \frac{B}{x-1}$. $A(x-1) + B(2x+1) = 5x+1$. If $x=1$, $3B=6 \implies B=2$. If $x=-1/2$, $-1.5A = -1.5 \implies A=1$. Integral is $\int \frac{1}{2x+1} dx + \int \frac{2}{x-1} dx = \frac{1}{2}\ln|2x+1| + 2\ln|x-1| + C$.
Problem 10.3

Use polynomial long division followed by partial fraction decomposition to evaluate the definite integral:

\[\int_{-1}^0 \frac{x^3 - 4x + 1}{x^2 - 3x + 2} \, dx\]
Warning: A problem this long is unlikely for a 2-mark multiple-choice question.
Long division gives $(x+3) + \frac{3x-5}{(x-1)(x-2)}$. Decompose the remainder: $\frac{A}{x-1} + \frac{B}{x-2} \implies A=2, B=1$. Integrate: $[\frac{x^2}{2} + 3x + 2\ln|x-1| + \ln|x-2|]_{-1}^0$. Result is $\frac{5}{2} + \ln(2) - 2\ln(2) - \ln(3) = \frac{5}{2} - \ln(2) - \ln(3)$.

Section C Question 1: Advanced Integration Techniques
Problem 1.1

Evaluate the indefinite integral using repeated integration by parts:

\[\int e^{-x} \cos(2x) \, dx\]
Approach: Let $u = \cos(2x)$ and $dv = e^{-x}dx$. Apply IBP twice. You will cycle back to the original integral. Move it to the left side of the equation and divide by the coefficient.
Result: $\frac{e^{-x}}{5} (2\sin(2x) - \cos(2x)) + C$.
Problem 1.2

Evaluate the indefinite integral showing all intermediate reduction steps:

\[\int (\arcsin x)^2 \, dx\]
Approach: Let $u = (\arcsin x)^2$ and $dv = dx$. Apply IBP. The resulting integral is $\int \frac{2x \arcsin x}{\sqrt{1-x^2}} dx$. Apply IBP again letting $u = \arcsin x$ and $dv = \frac{2x}{\sqrt{1-x^2}}dx$.
Result: $x(\arcsin x)^2 + 2\sqrt{1-x^2} \arcsin x - 2x + C$.
Problem 1.3

Evaluate the definite integral using integration by parts and a substitution:

\[\int_1^{\sqrt{3}} \arctan\left(\frac{1}{x}\right) \, dx\]
Approach: Let $u = \arctan(1/x)$ and $dv = dx$. Find $du = \frac{1}{1+(1/x)^2} \cdot (-x^{-2}) dx = \frac{-1}{x^2+1}dx$. The boundary evaluates to $x\arctan(1/x) |_1^{\sqrt{3}} + \int_1^{\sqrt{3}} \frac{x}{x^2+1}dx$. Use $w=x^2+1$ for the remaining integral.
Section C Question 2: Fundamental Derivations
Problem 2.1

Prove the derivative identity from scratch using implicit differentiation and right-triangle geometric bounds:

\[\frac{d}{dx}(\sec^{-1} x) = \frac{1}{x \sqrt{x^2 - 1}}\]
Approach: Let $y = \sec^{-1} x$, so $\sec y = x$. Differentiate implicitly: $\sec y \tan y \frac{dy}{dx} = 1 \implies \frac{dy}{dx} = \frac{1}{\sec y \tan y}$. We know $\sec y = x$. Use the identity $\tan^2 y = \sec^2 y - 1 = x^2 - 1$ to substitute $\tan y = \sqrt{x^2-1}$.
Problem 2.2

Let \(f(x) = 2 \arctan(\sqrt{x}) - \arcsin\left(\frac{x-1}{x+1}\right)\). Prove that \(f'(x) = 0\) for all \(x > 0\).

Approach: Apply chain rule carefully to both terms. The derivative of the arcsin term will require quotient rule inside the square root simplification. Both derivatives simplify to exactly $\frac{1}{x+1}$, meaning they subtract to $0$.
Problem 2.3

Prove the hyperbolic compound angle identity from exponential definitions:

\[\sinh(x+y) = \sinh x \cosh y + \cosh x \sinh y\]
Approach: Expand the RHS using $\sinh x = \frac{e^x - e^{-x}}{2}$ and $\cosh x = \frac{e^x + e^{-x}}{2}$. Multiply the fractions out algebraically. Four terms will cancel, leaving $\frac{e^{x+y} - e^{-(x+y)}}{2}$, which is the definition of the LHS.
Section C Question 3: Improper Integrals
Problem 3.1

Determine whether the improper integral converges or diverges by evaluating the limit of a definite integral:

\[\int_1^\infty x e^{-x^2} \, dx\]
Approach: Set up $\lim_{t \to \infty} \int_1^t x e^{-x^2} dx$. Use $u = -x^2$. The antiderivative is $-\frac{1}{2}e^{-x^2}$. Evaluating the limit as $t \to \infty$ gives $-\frac{1}{2}(0 - e^{-1}) = \frac{1}{2e}$. It converges.
Problem 3.2

Evaluate the improper integral with an infinite upper limit, or state with full limit justification why it diverges:

\[\int_1^\infty \frac{\ln x}{x} \, dx\]
Approach: Let $u = \ln x$. The integral evaluates to $\lim_{t \to \infty} [\frac{1}{2}(\ln x)^2]_1^t$. Because $\ln(t) \to \infty$, the integral diverges.
Problem 3.3

Locate the vertical asymptote, rewrite the integral as a limit, and evaluate or state divergence:

\[\int_0^1 \frac{\sec^2 x}{x\sqrt{x}} \, dx\]
Approach: The discontinuity is at $x=0$. Since $\sec^2 x \ge 1$ on $[0,1]$, we can compare it to $\frac{1}{x^{1.5}}$. By p-test ($p = 1.5 > 1$), $\int_0^1 \frac{1}{x^{1.5}} dx$ diverges. Therefore, the original integral diverges by comparison.
Section C Question 4: Comparison Test
Problem 4.1

State an upper-bounding comparison function \(g(x)\) and write a complete step-by-step proof showing that the improper integral converges:

\[\int_1^\infty \frac{x \sin x}{x^3 + 1} \, dx\]
Approach: Because $\sin x$ changes sign, take the absolute value to prove absolute convergence. $\left| \frac{x \sin x}{x^3 + 1} \right| \le \frac{x(1)}{x^3+1} < \frac{x}{x^3} = \frac{1}{x^2}$. Since $\int_1^\infty \frac{1}{x^2}dx$ converges ($p=2>1$), the integral converges absolutely, hence converges.
Problem 4.2

Use the Comparison Test to prove whether the improper integral converges or diverges:

\[\int_0^\infty \frac{\arctan x}{2 + e^x} \, dx\]
Approach: We know $\arctan x < \frac{\pi}{2}$ for $x > 0$, and $2+e^x > e^x$. So, $0 \le \frac{\arctan x}{2+e^x} < \frac{\pi/2}{e^x}$. The integral of $e^{-x}$ converges, so this converges by the Comparison Test.
Problem 4.3

Set up a lower-bounding inequality for \(x \ge 2\) and use the Comparison Test to establish whether the integral converges or diverges:

\[\int_1^\infty \frac{x+1}{\sqrt{x^4 - x}} \, dx\]
Approach: For large $x$, this behaves like $x/x^2 = 1/x$. Create a lower bound: $\frac{x+1}{\sqrt{x^4-x}} > \frac{x}{\sqrt{x^4}} = \frac{1}{x}$. Since $\int_1^\infty \frac{1}{x} dx$ diverges, our integral diverges by comparison.

Problem 5.1

Let \(\mathbf{u}\) be a non-zero vector and \(\mathbf{v}\) be arbitrary. Prove that the projection \(\text{proj}_{\mathbf{u}}(\mathbf{v})\) and the component \(\mathbf{v} - \text{proj}_{\mathbf{u}}(\mathbf{v})\) are orthogonal.

Approach: Let $\mathbf{p} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2}\mathbf{u}$. You must show $\mathbf{p} \cdot (\mathbf{v} - \mathbf{p}) = 0$. Expand: $\mathbf{p} \cdot \mathbf{v} - \mathbf{p} \cdot \mathbf{p}$. Substitute the formula for $\mathbf{p}$ and use dot product properties to show both terms equal $\frac{(\mathbf{u} \cdot \mathbf{v})^2}{\|\mathbf{u}\|^2}$, resulting in 0.
Problem 5.2

Use the result from Problem 5.1 and the Pythagorean theorem to prove that \(|\text{proj}_{\mathbf{u}}(\mathbf{v})| \le |\mathbf{v}|\).

Approach: Write $\mathbf{v} = \mathbf{p} + (\mathbf{v}-\mathbf{p})$. Since they are orthogonal, $\|\mathbf{v}\|^2 = \|\mathbf{p}\|^2 + \|\mathbf{v}-\mathbf{p}\|^2$. Because squared magnitudes are $\ge 0$, it follows that $\|\mathbf{v}\|^2 \ge \|\mathbf{p}\|^2$. Taking the square root gives the result.
Problem 5.3

Using the vector projection inequality and the explicit formula for projection, prove the Cauchy-Schwarz Inequality: \(|\mathbf{u} \cdot \mathbf{v}| \le |\mathbf{u}| |\mathbf{v}|\).

Approach: Substitute the magnitude of the projection formula into the inequality from 5.2. $\left| \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2}\mathbf{u} \right| \le \|\mathbf{v}\|$. Pull out the scalar absolute value: $\frac{|\mathbf{u} \cdot \mathbf{v}|}{\|\mathbf{u}\|^2} \|\mathbf{u}\| \le \|\mathbf{v}\|$. Multiply both sides by $\|\mathbf{u}\|$ to complete the proof.
